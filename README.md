# Asistente de Postulación Laboral

Proyecto de la **Clase 2** para construir un asistente que apoye el proceso de postulación laboral.

## Objetivo inicial

Definir y desarrollar un flujo que permita analizar una vacante, adaptar los materiales de postulación y preparar una candidatura clara y coherente.

## Estado

Repositorio inicializado. El alcance funcional y la tecnología quedan por definir durante la clase.

## Próximos pasos

1. Definir los casos de uso y el usuario objetivo.
2. Elegir la tecnología y la estructura de la aplicación.
3. Identificar los datos de entrada y los resultados esperados.
4. Implementar y probar el primer flujo del asistente.
